# 🎵 YTPlay: The Music Downloader & Converter

YTPlay is a modern web-based music downloader and converter that allows users to process YouTube videos and download audio in MP3 or M4A format. It combines a clean React interface with a TypeScript/Express backend powered by yt-dlp for efficient media processing.

## 🚀 Features

* 🎶 **YouTube Audio Download** - Download audio from YouTube videos.
* 🎧 **MP3 & M4A Support** - Convert and download audio in MP3 or M4A format.
* 🔗 **YouTube URL Processing** - Validate and process YouTube video URLs.
* 📥 **Direct Downloads** - Generate downloadable audio files directly from the application.
* 🌓 **Light & Dark Themes** - Switch between modern light and dark interfaces.
* ⚡ **Fast Processing** - Uses yt-dlp for efficient media extraction.
* 🎨 **Modern UI** - Built with React, Tailwind CSS, shadcn/ui, and Lucide icons.

## 🛠️ Technologies Used

* **Frontend:** React, TypeScript, Vite
* **Styling:** Tailwind CSS, shadcn/ui
* **State Management:** Zustand
* **Forms & Validation:** React Hook Form, Zod
* **Backend:** Node.js, Express.js
* **Media Processing:** yt-dlp
* **Code Editor:** VS Code
* **Version Control:** Git & GitHub

## 📱 How It Works

1. Paste a YouTube video URL into YTPlay.
2. Select the preferred audio format — MP3 or M4A.
3. YTPlay validates the URL and retrieves the video information.
4. Choose Download to extract and download the selected audio format.
5. For conversion, upload an MP3 or M4A file and select the desired output format.
6. YTPlay converts the audio file and provides the converted file for download.

## 🎯 Objective

The objective of YTPlay is to provide a simple, modern, and convenient interface for downloading and converting YouTube audio into commonly used formats without unnecessary complexity.
